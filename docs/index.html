    Documentación Técnica

    Estructura, instalación y despliegue del Portfolio Web y sus proyectos integrados.

    Resumen General

    Este repositorio aloja la solución completa del Portafolio Profesional desarrollado para la graduación del Grado Superior en Desarrollo de Aplicaciones Web (DAW).

    La aplicación actúa como portal central de la marca personal del desarrollador, mostrando proyectos, habilidades, información de perfil y una completa integración con Otaku Store, una aplicación e-commerce de demostración con sistema granular de roles, almacenamiento en carrito de compras y generación dinámica de catálogos en PDF.

    Características Principales:

    • Diseño de interfaz premium en verde bosque con efectos glassmorphic.
    • Frontend rápido basado en componentes reactivos con React y Vite.
    • Backend ligero API RESTful en PHP nativo para dinamismo de datos.
    • Sistema de base de datos relacional robusto en MySQL.
    • Panel de Administración integrado y protegido con token para edición dinámica de perfil y proyectos.

    Arquitectura y Tecnologías

    La plataforma se ha desarrollado empleando un stack robusto de tecnologías modernas, separando limpiamente las tareas de cliente y servidor:

    Frontend (Cliente)

    Construido como una Single Page Application (SPA) modular para asegurar tiempos de respuesta instantáneos:

    React 18 Vite React Router 6 Vanilla CSS Font Awesome 6

    Backend y API (Servidor)

    Desarrollado con una arquitectura orientada a servicios (API RESTful) que sirve respuestas estructuradas en formato JSON:

    PHP 8.x PDO MySQL JSON API FPDF Library

    Base de Datos

    MySQL con tablas relacionales normalizadas para optimizar la velocidad y la coherencia de datos:

    MySQL 5.7+ / 8.0 Charset utf8mb4 Collation utf8mb4_unicode_ci

    Configuración de la Base de Datos

    La base de datos utiliza la codificación utf8mb4 con la colación utf8mb4_unicode_ci para soportar correctamente caracteres especiales en español (acentos, la letra ñ, emojis, etc.).

    ¡Importante: Codificación de Caracteres!

    Para evitar que los acentos se corrompan (generando símbolos como ?? o ), la base de datos debe ser importada utilizando la conexión UTF-8. Evita canalizar volcados directamente a través de consolas locales que utilicen codificaciones ANSI por defecto.

    Estructura del Script de Base de Datos

    El archivo de base de datos se localiza en database/portfolio.sql y contiene el esquema de tablas y datos iniciales:

    database/portfolio.sql 
    -- Crear la base de datos con soporte completo UTF-8
CREATE DATABASE IF NOT EXISTS `portfolio_db`
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;

USE `portfolio_db`;

-- Tabla de proyectos con campos text para roles
CREATE TABLE IF NOT EXISTS `projects` (
  `id` INT AUTO_INCREMENT PRIMARY KEY,
  `title` VARCHAR(150) NOT NULL,
  `description` TEXT,
  `long_description` TEXT,
  `features` TEXT, -- Almacena JSON con los roles
  `technologies` VARCHAR(255),
  `image_url` VARCHAR(255),
  `project_url` VARCHAR(255),
  `github_url` VARCHAR(255),
  `category` ENUM('web', 'app', 'other') DEFAULT 'web',
  `featured` TINYINT(1) DEFAULT 0,
  `created_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

    Instalación y Ejecución en Local

    Sigue los siguientes pasos estructurados para configurar y lanzar la aplicación en tu entorno de desarrollo local:

    1
    Clonar el Repositorio

    Abre tu consola de terminal preferida o tu cliente Git y descarga el código fuente:

    Git CLI 
    git clone https://github.com/RotaruX/Portfolio.git
cd Portfolio
    2
    Configurar el Servidor MySQL y PHP (XAMPP)

    Mueve la carpeta del proyecto a la raíz web de tu servidor (ej. C:\xampp\htdocs\Portfolio en Windows).

    Inicia el panel de XAMPP y arranca los módulos de Apache y MySQL.

    Importa el archivo database/portfolio.sql a través de phpMyAdmin o directamente por consola asegurando el charset:

    MySQL CLI 
    c:\xampp\mysql\bin\mysql.exe -u root portfolio_db --default-character-set=utf8mb4 < database/portfolio.sql
    3
    Verificar Conexión de Base de Datos en PHP

    Abre el archivo de conexión del backend localizado en api/db.php y verifica las credenciales de base de datos de tu entorno:

    api/db.php 
    $db_host = 'localhost';
$db_name = 'portfolio_db';
$db_user = 'root';
$db_pass = ''; // Contraseña por defecto vacía en XAMPP
$db_charset = 'utf8mb4';
    4
    Instalar Dependencias de Node.js y React

    Abre la consola dentro de la carpeta del proyecto e instala las dependencias de Node definidas en package.json:

    Node CLI 
    npm install
    5
    Lanzar el Entorno de Desarrollo

    Ejecuta el servidor de desarrollo rápido provisto por Vite:

    Vite Dev Server 
    npm run dev

    El servidor arrancará por defecto en http://localhost:5173 (o el puerto que te indique la consola) y sincronizará en caliente tus cambios.

    Proyecto Otaku Store

    Otaku Store (con demo en otaku-store.es) es un sistema e-commerce completo implementado en la base de datos de proyectos, que posee un control granular de accesos según roles:

    Rol Icono Permisos Específicos Acciones del Carrito / Compra
    Invitado Navegar por el catálogo de productos, ver detalles (precio, descripción, imágenes), buscar y filtrar. Sin permisos: Debe registrarse o iniciar sesión para añadir productos al carrito o realizar compras.
    Usuario Registrado Todos los permisos del Invitado, gestionar su propio perfil y ver historial de compras. Permisos Completos: Añadir productos al carrito, modificar cantidades, eliminar artículos y finalizar compra.
    Administrador Agregar nuevos productos, editar y eliminar existentes, gestionar usuarios registrados, acceder al panel interno. Catálogo PDF: Generar, visualizar y descargar un catálogo completo de productos en formato PDF usando la librería FPDF.

    Portfolio Web - Características

    La web principal de portafolio cuenta con un diseño visual de primer nivel e interactividad inteligente:

    Diseño Verde Bosque Premium

    Uso de variables CSS para el control unificado de la paleta. Fondos oscuros con contrastes verdes menta y esmeralda. Efecto de desenfoque de fondo glassmorphic tras cabeceras y tarjetas.

    Fondo de Partículas Interactivas

    En el Hero de la página principal se carga un fondo animado en canvas con física de partículas conectadas que reacciona a la posición y movimientos del cursor del ratón.

    Autenticación de Administrador

    El portal incluye un formulario de login y recordatorio inteligente de credenciales (usando almacenamiento seguro del navegador/LocalStorage). Permite acceder a un panel exclusivo para modificar la información expuesta sin alterar el código fuente directamente.

    Despliegue en GitHub Pages

    GitHub Pages es el servicio oficial de alojamiento estático de GitHub. Al ser un portafolio web que consta de archivos HTML, CSS y JavaScript construidos, es una opción óptima para hospedar la documentación o la interfaz estática:

    Estructura del directorio /docs

    Hemos alojado esta documentación dentro de la carpeta /docs en la rama principal. Esto permite utilizar la configuración nativa de GitHub Pages para publicar el sitio de documentación de forma inmediata sin necesidad de ramas auxiliares.

    Pasos para activar GitHub Pages desde tu Repositorio:

    1
    Subir la carpeta al Repositorio de GitHub

    Abre la aplicación GitHub Desktop. Verás que detecta automáticamente los archivos añadidos en la carpeta docs/.

    Introduce un mensaje de commit (ej. Añadida documentación en español en docs/), haz clic en **Commit to main** y finalmente pulsa **Push origin** para subir los cambios a tu repositorio remoto en GitHub.

    2
    Configurar GitHub Pages en la Web

    Accede a tu cuenta de GitHub, navega al repositorio RotaruX/Portfolio y sigue estos clics:

    1. Entra a la pestaña de Settings (Configuración) en la barra superior del repositorio.

    2. En el menú lateral izquierdo, haz clic en Pages (dentro del grupo Code and automation).

    3. En el apartado de Build and deployment, localiza la sección Source y comprueba que esté en "Deploy from a branch".

    4. En el selector de Branch (Rama), cambia None por la rama principal main.

    5. Justo al lado, cambia la carpeta raíz / (root) por la carpeta /docs.

    6. Haz clic en el botón Save (Guardar).

    3
    Acceder al Sitio Web de Documentación

    GitHub creará una tarea de construcción en segundo plano (puedes verla en la pestaña Actions). Tras 1 o 2 minutos, la URL de publicación estará activa y se mostrará al principio de la página de Pages con la siguiente estructura:

    https://rotarux.github.io/Portfolio/
